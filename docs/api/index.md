# API リファレンス

名前空間ごとに、公開クラス・メソッド・プロパティの一覧を掲載しています。
説明はソースコードの XML ドキュメントコメントから生成されています。

| 名前空間 | 内容 |
|---|---|
| `Twikit` | `Client`、モデル（`Tweet`、`User`、`Message`、`TwitterList`、`Community` など）、`Result<T>`、例外 |
| `Twikit.Api` | GraphQL / v1.1 のエンドポイント層（`GqlClient`、`V11Client`）とリクエストの型 |
| `Twikit.Streaming` | ストリーミング（`StreamingSession`、`Payload`、`Topic`） |
| `Twikit.Spaces` | X スペース（`Spaces`、`Space`、`SpaceChat`、`ProxseeApi`、`ChatmanApi`、`JanusClient`、`SpaceVoiceSession`） |
| `Twikit.Guest` | ゲストクライアント（現在 X 側で閉じられています） |
| `Twikit.Transaction` | `X-Client-Transaction-Id` ハンドシェイク |
| `Twikit.Captcha` | captcha ソルバー（`Capsolver`） |
| `Twikit.UiMetrics` | ui_metrics チャレンジのソルバー |
